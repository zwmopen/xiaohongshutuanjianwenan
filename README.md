# 小红书团建文案 Skill（公开版）

这是可公开分享、可直接交给 ChatGPT / Codex / 其他大模型使用的团建文案技能包。

## 公开版定位

本仓库是 **公开发行版（Public Edition）**，只保留可分享的通用文案能力：

- 小红书1｜自然攻略版
- 小红书2｜高密度种草版
- 抖音｜攻略版（安全/无营销处理）
- 标题钩子、事实边界、手机排版、Emoji、SEO、长度控制
- 高密度种草的参数卡、亮点速览、参考时间轴、玩法池

不会公开：

- 私有素材库、内部同行原文库
- 客户/公司/订单/WorkId 等业务数据
- 本地路径、账号、自动化生产线、API/CDP 私有配置
- 未公开的内部验证数据和私有生产脚本

## 怎么用

把本仓库的 `SKILL.md` 和 `references/` 一起交给模型，然后直接输入你的团建素材或原文，默认输出三版：

1. 小红书1｜自然攻略版
2. 小红书2｜高密度种草版
3. 抖音｜攻略版

也可以明确说“只要高密度版”“只要抖音版”。

## 版本关系

- **私有版**：内部完整真源，包含更多原料、自动化和生产规则。
- **公开版**：从私有版同步出的可分享精简发行版。

凡是影响公开用户实际成稿行为的通用规则变更，会同步到本仓库；内部专属数据和生产基础设施不会同步。

详见：`SYNC_POLICY.md`。
