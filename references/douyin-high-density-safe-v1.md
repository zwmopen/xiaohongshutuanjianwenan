# 抖音｜高密度攻略版（无营销）V1

## 定位

**高信息密度 + 高可扫读 + 低营销 + 普通用户口吻 + 平台安全**

## 保留
- 具体项目型标题
- 3—5行高密度开场
- Emoji 导航
- 玩法分组
- 参考时间轴
- 选择分流
- 简化玩法池
- 统一提醒

## 删除/弱化
- HR / 行政
- 10人起接
- 大巴接送可安排
- 可定制 / 一站式
- 报价 / 私信 / 咨询 / 预约 / 下单
- 人数+日期
- 服务商承接口吻
- 单目的地中过度堆叠“团建方案/团建推荐”

## 标题
优先普通用户场景：
- 千岛湖秋天｜骑行+落日+露营这样玩
- 安吉两天｜采摘+围炉+温泉怎么搭
- 莫干山秋游｜第一天撒野第二天进山
