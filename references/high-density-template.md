# 小红书2｜高密度种草版

## 核心感觉

高密度种草版 = 搜索型标题 + 情绪第一屏 + 参数卡 + 亮点速览 + 参考时间轴 + 玩法池 + SEO话题。

目标不是“安全精简”，而是**事实准确前提下尽量丰富**。

## 标题

优先：
`地点团建｜强玩法A+强玩法B+强玩法C🍂`

标题要有具体项目/场景，不要只写“怎么玩/怎么选”。

## 第一屏

建议3—5行：
1. 季节或打工人情绪钩子
2. 为什么值得去
3. 高密度玩法概览
4. 一句“可收藏/可抄作业”的结果感

## 参数卡

```text
📍 | 地点
⏰ | 时长
🙋‍♀️｜人数（有依据才写）
🚌 | 交通/接送（有依据才写）
🎯 | 3—4个核心体验
```

## 亮点速览

每项不是只列项目名，而是：

`项目名 + 具体画面/体验 + 一句判断`

通常4—6项。

## 参考时间轴

素材明确时长后，可以主动规划合理参考时间：

```text
🗓️ 1日行程参考
09:30｜集合/抵达
10:00｜核心项目
12:00｜午餐
14:00｜下午项目
16:30｜休闲/围炉
18:00｜晚餐/烧烤
19:30｜返程或夜间活动
```

这是策划参考，不是官方营业时间。

## 玩法池

素材足够时保留9—15项，例如：

`骑行🚴｜采摘🍊｜飞盘🥏｜烧烤🔥｜围炉🍵｜手作🎨`

主路线做减法，玩法展示做加法。

## 选择分流

可增加2—3组：

`✅偏热闹：A+B+C`

`🌿偏松弛：A+B+C`

## SEO话题

通常8—10个，覆盖：
- 地域
- 具体目的地
- 核心项目
- 季节
- 团建
- 时长/场景

## 排版

仅使用一行 U+2800 作为段落间距：

`⠀`

不使用独立 `•` 做空行。

## 长度

素材充足时目标900—980字符，1000字符以内。
