# 公开版成稿规则

## 默认三版

1. 小红书1｜自然攻略版
2. 小红书2｜高密度种草版
3. 抖音｜攻略版

历史“大纲方案版”不再默认输出。

## 小红书总体方向

小红书优先：
- 丰富
- 好搜
- 好收藏
- 有项目密度
- 有Emoji和视觉层级
- 有团建、HR、方案等业务语义

不要把抖音安全规则套到小红书上。

## 抖音总体方向

抖音单独做平台安全处理：
- 去强商业承接
- 去报价/预约/私信/下单等转化词
- 单目的地更像普通用户玩法分享
- 多目的地合集可适度保留团建SEO

## 手机排版

段落之间统一：

`⠀`

即 Unicode U+2800。

不要使用：
- 裸空行
- &nbsp;
- <br>
- 独立圆点作为空行

## 长度

- 小红书自然攻略：通常650—850字符
- 小红书高密度种草：素材充足时900—980字符，1000以内
- 抖音：通常450—650字符

字符统计应计入标题、正文、标点、Emoji、U+2800与话题。

## 发布稿净化

最终文案禁止出现：
- 原文
- 原稿
- 原素材
- 图片里
- 根据资料
- 素材显示
- 这份素材
- 本文整理

有事实就直接写；没事实就删；风险提醒集中到结尾。


## 2026-10-22｜字数下限硬门：禁止成稿过短

用户反馈：当前成稿实际阅读体感偏短。以后不只控制“不要超长”，还必须执行**最低字数硬门**。

默认目标按“最终发布态总字符”执行（标题 + 正文 + Emoji + 标点 + U+2800 + 话题均计入）：

- **小红书1｜自然攻略版：650—850字符**
  - 素材充足时 **<650 直接判 underfilled，必须补写**；
  - 不能只写成 400—500 字的简版攻略。
- **小红书2｜高密度种草版：900—980字符**
  - 素材充足时 **<900 直接判 underfilled**；
  - **1000字符以内即可**，不用主动压到700—800。
- **抖音｜攻略版：450—650字符**
  - 素材充足时 **<450 直接判 underfilled**；
  - 仍保持单目的地的安全/弱营销规则。

补字优先级：
1. 补玩法差异和具体体验；
2. 补合理的选择建议 / 团队取舍；
3. 补参考节奏 / 时间轴（高密度版可主动规划参考时刻）；
4. 补项目池、组合建议、必要提醒；
5. 补搜索话题。

禁止为了凑字数编造价格、车程、容量、客户案例、营业时间、项目开放状态。

**执行要求：生成后必须实际计数；低于对应下限时先重写再交付。**


## 2026-10-23｜抖音升级：高密度攻略骨架 + 无营销

默认第三版抖音不再追求“越安全越短”，而改为：
**高密度攻略骨架 + 普通用户口吻 + 去营销处理**。

保留：
- 强标题
- 高信息量开场
- Emoji
- 玩法亮点
- 参考时间轴
- 选择分流
- 简化玩法池

删除/弱化：
- HR、行政、10人起、大巴接送、可定制、一站式
- 报价、私信、咨询、预约、下单、人数+日期
- 服务商承接口吻
- 单目的地中过度堆叠“团建方案/团建推荐”

抖音仍控制约 **450—650字符**，但要求“高密度、低营销”，不是“低密度安全版”。
